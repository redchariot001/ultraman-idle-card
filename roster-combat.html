一、选角原则与基准

  1. 选角池：以已上线版本英雄（约 149 名）为基准，从中筛选初版可玩角色；赛罗小队中火焰战士、镜子骑士、钢铁武士三位为项目既有设定，一并纳入。
  2. 主线剧情顺序：初版内容按「赛罗剧场版 → 串联迪迦 / 泽塔 → 欧布 → 捷德 → 罗布」的版本顺序推进，选角向该顺序的高人气角色倾斜。
  3. 形态取舍：基础形态优先入选；高级进阶形态优先采用赛罗与迪迦版本内容；版权以新创华授权范围为准——赛文、泰罗等新创华未获版权的角色不纳入（即便其在奥传2已上线）。
  4. 稀有度两档：全角色仅「稀有 / 超稀有」两档，终身固定。
  5. 阵营归属规则：严格遵循项目定稿的「阵营世界观映射」（见下），不按印象自造。
  6. 职业覆盖：四大常规阵营（光之国度 / 群星之光 / 巨兽荒原 / 暗星盟约）各自内部须覆盖六大职业、每种至少 1 名；光暗六神魔（宇宙传说 + 星域霸权）合计覆盖六大职业各 1 名。
  7. 稀有度判定：有明确后续强化形态的基础形态优先定稀有，包括捷德原始、泽塔原始及本次采用标准形态的杰斯提斯。后续强化形态单独评估；平行属性形态、首次出场形态和多人合体本身不决定稀有度。常态赛罗、高斯月神和迪迦复合型按已确认方案采用超稀有。常规阵营每阵营至少 6 名超稀有的目标继续记录，当前配额见统计。

定位标签说明

预设标签用于指导初版技能设计，优先标出角色的主要伤害方式与标志性机制。“物攻”统一写作“物理”，“召唤物”统一写作“召唤”。“群攻”作为伤害覆盖标签单列，可与任意机制标签并用。

类别标签标注条件
伤害类型能量、物理、真伤按计划采用的伤害类型标注。附带招牌终结技时可同时标注能量和物理；真伤需要技能明确按真实伤害结算
生存与恢复护盾、治疗护盾指形成可吸收或拦截伤害的屏障；治疗指回复生命，包括具体技能允许的自疗或友方治疗
单位与联动召唤、追击召唤指生成有独立战场行为的单位；追击指由条件或队友行为触发追加进攻
状态效果控制、负面、增益控制限制或打断行动；负面标记削弱、持续伤害等效果；增益提供属性、回能或协同收益。复合技能可同时标多个
针对效果破盾、减防破盾指对护盾额外消耗或移除；减防指明确降低护甲、魔抗或对应防御属性
伤害覆盖群攻常用或标志性伤害技能可同时命中多个敌人

标签是预设。巴尔坦星人的分身按可参与战斗的召唤单位设计，欧布猛斯王的分体按召唤方向预留。雷欧和雷德王预留破盾能力，加恩 Q 和贝姆斯塔的护盾标签指将吸收能力转成护盾机制的设计方向。真伤和减防暂保留在词表，待技能明确后分配给具体角色。

一、框架概览

挂机产品不是“挂机收益 + 抽卡”两个系统并列。玩家在卡关点需要看懂：卡在哪里、哪些方式能改善、每种方式要花多少时间／资源／钱，以及投入后是否仍有其他可走路径。

图中的资源和付费都是不同的解法。卡关诊断决定玩家先看哪条路；可见入口决定玩家知道哪些路存在；稳定产出与限时购买决定玩家能多快走完。三者断开时，玩家会觉得“系统很多，但我不知道从哪里成长，也不知道钱能买什么”。

核心判断

玩家的痛点由三类缺口叠加而成：

  1. 节奏差异缺口：卡档将进度奖励分段，早到的玩家主要先拿固定奖励；后续追赶者并不必然以同样比例永久落后。领先的价值更接近“提前取得资源和排名窗口”，而非长期占有更高的日常资源斜率。
  2. 成长可见性缺口：卡关后经验、装备和其他成长材料分散在挂机、成就、任务、首通与限次入口，玩家没有一个可信的全局解法面板。
  3. 愿付需求与可买商品缺口：玩家有战力提升意愿，但赛季装备／回响更迭或重置，叠加稳定购买入口缺失，使“我愿意花钱”与“这里有适合我买的东西”分离。

二、六项观察与系统问题

玩家侧观察当前体验对应的系统缺口
1. 主要计费围绕角色卡池、角色养成和加速通行证抽取角色、培养角色和缩短等待是主要购买理由核心付费与角色成长耦合，其他成长模块没有同样清楚的商品与购买时机
2. 重氪集中在品阶、专武、回响及附属模块深度付费主要加深已有核心角色与附属养成高价值养成路线偏窄；购买理由依赖少量明星角色与高段位追求
3. 多段卡档允许重氪领跑，但资源产出大体固定领跑者提前取得阶段奖励；追赶者可以随后拿到同类资源竞争优势集中在时间与排名窗口，未必形成长期资源产出优势；这是公平追赶设计，也限制持续加速的价值表达
4. 卡关想升角色等级，但经验入口分散且难以感知挂机最直观；其他经验可能要完成任务、成就或挑战后才发现缺少“当前短板 → 所有可得资源 → 每种来源数量／条件 → 一键跳转”的统一入口
5. 想用装备、回响补战力，却找不到明确购买方式相关养成迭代快且可能赛季重置；愿付玩家不易找到可信补充时效性、购买可见性与商品价值没有对齐；购买后的保值预期不足
6. 卡关有时由阵容和站位决定玩家自行换人、改位、重试，逐步碰出解法战斗信息不能充分解释“为什么输、换什么可能有效”；阵容知识难传递，试错成本偏高

关系链

关卡难度上升
   ├─ 数值不足 → 要等资源／找不到资源入口 → 对加速付费的收益不确定
   ├─ 角色深度不足 → 抽取或升阶，但购买决策集中在少数角色
   ├─ 装备或回响不足 → 赛季时效和补充入口不清晰 → 付费动机被削弱
   └─ 阵容不适配 → 不知道换谁／站哪 → 反复试错，误以为只能继续堆数值

因此，卡关不是一个单一的数值问题。产品需要先诊断失败成因，再展示对应成长与策略路径；付费选项应在对应路径上出现，并标明成本、持续期与替代来源。

4.2 永久资产与赛季资产分工

本项目之前已确定：英雄品阶、专武、角色回响按永久线设计；赛季重心继续放在赛季装备、阶段资源、赛季挑战与主题收藏。变身器同样永久保留。新的收费设计要与这条分工一致：

  • 重度付费主轴：定向角色获取与永久角色深度培养，使高投入有持续资产和可预期目标。
  • 中度付费主轴：月度／赛季预算明确的角色卡池计划、阶段养成包、外观收藏、可规划的队伍深度。
  • 轻度付费主轴：通行证、低额月卡和小额资源包，提供稳定价值与有限时间加速。
  • 赛季商品主轴：赛季装备和回响可作为当季策略工具销售；如果每季结束回收，商品要按期限价值定价、限制重复逼购，并提供免费构筑路线。
  • 辅助收入：舰队外观、收藏、生活互动与便利功能拓宽题材消费，不把所有收入压力塞回角色抽卡。

短期装备即使能卖，也未必适合承载高价永久投资。反过来，临时性本身也不等于不能付费；关键是价格、持续期、获取保底和失败后的补偿是否让玩家预期一致。

4.3 卡档追赶与付费价值

固定产出的阶段奖励适合平衡服务器进度、缩小纯资源差距，但让高投入的价值主要表现为提前领取。为避免“氪了只早几天、之后都一样”的挫败，需要明确三种不同价值：

  1. 进度时间：能提前打到哪一段，先体验什么内容。
  2. 竞争窗口：排名、限时挑战或公会目标中，提前成长能换得什么可见奖励。
  3. 长期资产：角色、专武、角色回响、永久变身器或收藏在赛季之后仍留下什么。

服务器追赶不应追收永久角色资产。追赶资源补偿的是同赛季的可玩进度；永久成长目标保留玩家长期投入的价值。

角色卡池与永久养成形成收集和长期付费深度角色、品阶、专武、角色回响一次获得角色就把全部长期成长删掉
卡关导航把隐藏来源变成玩家能找到的路线任务和玩法跳转、材料缺口、建议行动为卖礼包而掩盖免费已得资源
阵容学习解释战斗结果并降低无效重试站位、技能范围、克制／机制提示、试阵把所有解法都锁在付费英雄上
赛季养成给当季构筑和关卡新鲜感装备、回响、临时强化、主题玩法赛季重置时抹掉永久角色和舰队投入
母舰、星球与好感长线主题、运营和叙事承载建设、收藏、关系、舰队外观及补充资源成为共鸣升级和挂机推进的强制门槛

六、体验闭环与玩家界面

6.1 卡关页要回答五个问题

  1. 我这次为什么输？
  2. 什么改变最可能有效：等级、角色技能、装备还是阵容？
  3. 现在哪些免费奖励或任务已可领取？
  4. 自然收集这些资源要多久；有哪些加速选择，额度和价格是什么？
  5. 赛季结束后这件商品／装备／回响会不会保留？

6.2 资源入口架构

每种成长资源有“资源说明页”，列出稳定来源、周期、一次性来源、限购次数、当前已领取与下次刷新，并可跳转。成就与引导奖励继续存在，但都进入同一资源索引，不成为只有玩家偶然点开才发现的隐藏经济。

挂机奖励页同时显示当前关卡档位与收益构成；额外领取按钮旁显示每日可购买次数、当次资源拆分和上限，不用玩家先购买才知道经验有多少。

6.3 阵容试错工具

  • 保存多个阵容和站位预设，训练／重试不消耗关键资源。
  • 战报提示首个减员时间、主要伤害来源、技能命中／落空、控制生效情况与最后胜负原因。
  • 给 1–3 个明确的可尝试方向，例如“把远击位移到另一列，避开开场直线技能”或“试用一个能打断蓄力的单位”。
  • 允许同条件快速重播，显示本次相对上次改变的要素；系统建议保持可跳过，不代替玩家布阵。
  • 对不同方案使用实战结果而非未经解释的“推荐战力”打分，避免误导。

6.4 商品呈现时机

商品在已经解释的需求旁出现：缺角色时展示目标获取进度；经验不足时展示免费来源与有上限的加速选项；装备短缺时展示稳定产出和明确的限时补充；想要外观时展示永久归属。所有推荐都能关闭，不阻止查看免费途径。

七、关键设计原则

  1. 资源来源可见：获得经验或装备前后都有来源记录，玩家不用靠事后猜测。
  2. 自然成长可计划：显示当前积累速度、收益上限和到达目标的大致时间。
  3. 付费买到明确价值：明确是角色、永久成长、时间、当季构筑还是外观，并标明期限与获取替代。
  4. 卡档缩短差距，不抹平资产：阶段资源可以追赶，永久角色养成和收藏留下来。
  5. 数值门槛与战术门槛并存：玩家既可以培养，也能通过理解机制改进结果。
  6. 阵容知识可发现：告诉玩家敌人机制、可行的反制方向和试用入口，不强迫唯一答案。
  7. 核心和支线不互相绑架：挂机与英雄基础成长不依赖舰队、地图、好感或赛季收藏。
  8. 成就奖励仍有价值但不隐身：成就可承担阶段奖励，不应代替常规资源面板与稳定供给。
  9. 限额明示：每日购买上限、补领次数、通行证周期和赛季重置时点在购买前展示。
  10. 同一资源有主来源和补充来源：主来源保证长期可持续，支线提供额外节奏与主题奖励。

八、可观察的产品指标

先记录基线，再按关卡区间、付费层级、新老赛季和卡关原因切片；不预设没有数据支持的目标数值。

问题建议观测
玩家是否看见成长途径卡关页打开率、来源列表点击率、可领资源发现率、导航完成率
付费是否解决已知需求推荐商品点击／购买后目标达成率、免费／付费路径的转化与退出
卡档是否带来有意义领跑早期奖励领取时点、卡档前后留存、追赶耗时、排名奖励差距
装备短缺是否成为断供分装备等级的材料缺口、无可重复来源的天数、装备升级停滞人数
阵容试错是否可学习重试次数、站位／英雄变更比例、诊断打开后胜率变化、退出率
长期商品是否有保值感永久资产获取后跨赛季使用率、赛季商品购买后使用时长和评价
资源入口是否过度分散奖励领取前后页面数、遗漏率、资源索引覆盖率

指标用于找到断点，不能把“点击更多礼包”当作唯一成功标准。若卡关页提高了购买点击但同时提高退出率，说明推荐可能加重压迫感。
